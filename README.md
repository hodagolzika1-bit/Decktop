# 🏋️‍♂️ Gym Members Management System (CRUD App)

A lightweight CLI application built using **Python** and **SQLite3** to manage gym members. This system implements full **CRUD** (Create, Read, Update, Delete) operations with built-in input handling and database constraints.

## ✨ Features
- 🔄 **Continuous Loop**: Stays open using a `while True` logic until explicitly closed.
- 📥 **Create**: Stores new members with formatted capitalization.
- 📋 **Read**: Lists all registered gym profiles efficiently.
- 🆙 **Update**: Modifies current profiles smoothly via unique User IDs.
- 🗑️ **Delete**: Safely discards entries from the system.
- 🛡️ **Validation Included**: Features code blocks designed to catch formatting errors (like values entering fields expected to hold numbers).

## 🛠️ Technical Stack
- **Language:** Python 3
- **Database:** SQLite3
